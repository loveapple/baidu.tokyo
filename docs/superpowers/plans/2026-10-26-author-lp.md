# Author LP Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 承認された著者・書籍紹介LPをbuild/testしDraft PRでレビュー可能にする。
**Architecture:** 単一Astroページ、静的アセット、通常CSS。生成物をNode標準test runnerで検査する。
**Tech Stack:** Astro、TypeScript、@astrojs/sitemap、Node.js 24、GitHub Actions。
**Spec:** ../specs/2026-10-26-author-lp-design.md

## Global Constraints
- 著者ブランドと既刊著者名、経済書と今後の執筆テーマを区別する。
- 本番公開、DNS変更、VPS操作、mainへのLPマージをしない。
- クライアントJS、フォーム、DB、依頼外サービスを追加しない。

## Review Focus
- project Pagesのbase配下でCSS・画像・canonical・sitemap・robotsが一致する。
- PRからdeployせず、mainでも公開承認変数なしにはdeployしない。
- Amazon表紙が取得不能でもタイトルと紹介は読める。
- 小画面・拡大表示で本文がはみ出さず、キーボードでリンクに到達できる。
- 未確認の書籍情報・開始予告を出力しない。
