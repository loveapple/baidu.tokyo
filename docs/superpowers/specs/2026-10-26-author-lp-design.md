# 著者・電子書籍LP 設計

2026-10-26、ユーザー承認済みの方針と追加条件を記録する。

## 目的・範囲
- Astroで日本語の単一静的LPを作る。著者活動のブランドは燊然居士。
- Hero → 既刊書籍 → 著者紹介 → 今後の執筆テーマ（易経・64卦）→ Footer。
- Hero: 「易を読み、変化を考える。六十四卦に映る、経営と人生の選択。」
- 既刊は『脱依存の経済学: 中国「去依附」から読む、日本の国益・円安・資源危機』。著者名はAmazonの「郝　春利」を維持し、経済・社会評論として紹介する。
- 易経の新刊・サービス開始・日程を予告しない。LINE、AIエージェント、ニュース収集、会員登録、DBは実装しない。

## Approaches
- 採用: Astro単一ページ＋通常のCSS。クライアントJavaScriptなしで、軽量さと保守性を優先する。
- 不採用: SPAやCMS。今回の固定された紹介ページには追加ランタイムや編集基盤が不要。
- 不採用: Sitesへのホスティング。指定のGitHub Pagesと異なるため使わない。

## 表現と情報源
- 和紙色、墨色、朱色、明朝見出し。六爻をモチーフにした装飾はCSS/SVGで作る。細部は実装者判断として委任済み。
- 書籍タイトル・著者名・紹介・表紙はAmazon商品ページ、略歴はAmazon著者ページに基づく。出典と確認日をdocs/sources.mdに残す。
- 価格・販売順位など変動する情報は載せない。未確認の実績・肩書き・書籍は追加しない。

## 配信・QA
- 初期配信先は https://loveapple.github.io/baidu.tokyo/ 。canonical/OGP/sitemap/robotsはこのURLに揃える。
- GitHub ActionsでPR時にbuild/test。mainへのpush時は公開承認用のrepository variableがtrueの場合のみPagesへ自動デプロイ。
- DNS、旧VPS、Pages設定、公開承認用変数は変更しない。CNAMEは追加しない。
- build、Astro型検査、生成HTML/URL/画像/禁止内容の回帰検査、ブラウザー表示、自己レビューを行いDraft PRを作る。mainへLPをマージしない。
- 空リポジトリのPR比較先として、ファイルを持たない初期コミットのみmainに作成する。サイトは作業ブランチ内に留める。
